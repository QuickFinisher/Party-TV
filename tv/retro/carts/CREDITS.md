# Bundled homebrew games

Both are free games made for real Game Boy hardware, built from their public source code.

| Game | Author | License | Source |
|---|---|---|---|
| µCity (`ucity.gbc`) — city-building sim for Game Boy Color | Antonio Niño Díaz (AntonioND) | GPL-3.0 (see `LICENSE-ucity-GPL3.txt`) | https://github.com/AntonioND/ucity — built from commit 71fb08e7ca53fe4228e66316968d9c6bea3439ba |
| Libbet and the Magic Floor (`libbet.gb`) — puzzle game | Damian Yerrick (PinoBatch) | zlib (see `LICENSE-libbet-zlib.txt`) | https://github.com/pinobatch/libbet — built from commit 1232e71dc1ac852786ad9825316e19d2b341bc4a |

Built with RGBDS v1.0.4 (https://github.com/gbdev/rgbds).
